# fusion-hermes-v1: Privacy Policy

fusion-hermes-v1 is a private, unpublished Reddit Developer Platform app used only by its author, u/Lord_Fusion.

**What it reads.** Public posts in r/homelabsales and r/hardwareswap: title, body, flair, author username, post time,
links, and whether the post was edited, deleted or removed.

**Where it goes.** Each new or changed post is sent to the author's private Discord channel through a Discord webhook,
for the author's personal deal-finding. Discord is the only third party involved. Nothing is sold, shared or used for
advertising.

**What it stores.** Only each post's id and a hash of its content, in the app's Reddit-hosted storage, for up to 14
days, so the same post is not sent twice. No user accounts, no data about the people who view or install the app.

**Deletions.** When a post is deleted or removed on Reddit while the app still reads it, that change is forwarded too,
so the author's downstream copy is removed.

**Contact.** Send modmail to r/fusion_hermes_v1_dev.
